这是什么

SkillForge 是一个本地优先的 Skill 管理平台：集中管理你的 Skill，组合成「专家」，一键复制给 Codex / Claude Code 使用。所有数据只保存在你的电脑。

📖

快速上手

  1. 点顶部「浏览文件夹」选择 Skills 仓库目录
  2. 点「重新扫描」加载 Skill 列表
  3. 卡片上可直接 安装 / 使用 / 删除
  4. 勾选卡片可批量安装、批量删除
  5. 「我的专家」组合 Skill，生成专家口令
💾

数据存储

配置与专家数据保存在应用目录下的 data/ 文件夹（打包为 exe 时位于 exe 旁边）。数据不会上传到任何服务器。
